# AI Code Detector - College Micro Project

## Features
- Python Flask backend
- HTML/CSS/JavaScript frontend
- Paste code and analyze it
- Heuristic AI-like signal score
- No external API required
- Runs locally in VS Code

## Requirements
Python 3.10+ recommended.

## Run
Open this folder in VS Code, then run:

```bash
pip install -r requirements.txt
python app.py
```

Open:
http://127.0.0.1:5000

## Important
This is an educational heuristic detector. It cannot reliably prove whether code was written by a human or AI.
